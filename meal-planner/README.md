# 🍽️ מתכנן ארוחות וקניות שבועי (Meal Planner PWA)

אפליקציית ווב מתקדמת (PWA) לתכנון ארוחות שבועי וניהול רשימת קניות חכמה.
כל האפליקציה רצה בצד הלקוח בלבד (HTML + CSS + JavaScript טהור, ללא שרת
וללא בסיס נתונים) והנתונים נשמרים במכשיר שלכם בעזרת `localStorage`.
לאחר טעינה ראשונה האפליקציה ממשיכה לעבוד **גם בלי אינטרנט**, וניתן
להתקין אותה על מסך הבית של הטלפון כמו אפליקציה רגילה.

## ✨ מה יש באפליקציה

1. **המזווה שלי** - הוספה, עריכה ומחיקה של מצרכים שכבר יש לכם בבית, עם
   כמות ויחידת מידה (ק"ג, גרם, יחידה, חבילה, כוס ועוד).
2. **תכנון ארוחות** - הקלידו שם מנה בעברית או באנגלית (למשל "שניצל" או
   "Schnitzel") ושייכו אותה ליום מסוים בשבוע. האפליקציה מזהה אוטומטית
   מתכון קיים מתוך 20 מתכונים ישראליים מובנים, ומאפשרת לערוך את הרכיבים
   לפי הצורך. גם אפשר ליצור מתכונים אישיים חדשים.
3. **רשימת קניות חכמה** - האפליקציה משווה בין הרכיבים הדרושים לכל
   הארוחות המתוכננות לבין מה שכבר יש במזווה, ומציגה רק את מה שבאמת
   חסר - כשהוא מקובץ לפי קטגוריות (ירקות, בשר, מוצרי חלב וכו'), עם
   אפשרות לסמן פריטים כ"נקנה", להעתיק את הרשימה ללוח, או לשתף אותה
   בוואטסאפ.
4. **תצוגה שבועית** - לוח שבוע (ראשון-שבת) עם כל הארוחות המתוכננות לכל
   יום, וסיכום כמות הפריטים לקנייה.

כל הנתונים (מזווה, תכנון, מתכונים אישיים, פריטים שסומנו כנקנו) נשמרים
בזיכרון המכשיר ונטענים אוטומטית בכל פתיחה מחדש.

## 🗂️ מבנה הקבצים

```
meal-planner/
├── index.html            עמוד האפליקציה
├── manifest.json          קובץ ה-manifest של ה-PWA
├── service-worker.js      Service Worker לתמיכה באופליין
├── css/styles.css         עיצוב נוסף מעבר ל-Tailwind
├── js/
│   ├── app.js             לוגיקת האפליקציה, רינדור וניהול אירועים
│   ├── recipes.js         בנק המתכונים, קטגוריות ויחידות מידה
│   └── storage.js         שכבת שמירה ב-localStorage
├── icons/                 אייקונים להתקנה (נוצרו ע"י scripts/generate-icons.mjs)
└── scripts/generate-icons.mjs   סקריפט Node ליצירת האייקונים מחדש
```

## 🚀 איך מריצים מקומית

חשוב: Service Worker לא עובד כשפותחים את הקובץ ישירות מהדיסק
(`file://`) - צריך שרת HTTP מקומי (גם `localhost` נחשב "בטוח" מבחינת
הדפדפן).

בחרו אחת מהאפשרויות:

```bash
# עם Node.js (מובנה, לא דורש התקנה):
cd meal-planner
npx serve .

# או עם Python:
cd meal-planner
python3 -m http.server 8080
```

לאחר מכן פתחו בדפדפן את הכתובת שמוצגת (למשל `http://localhost:8080`).

## 📲 איך מתקינים על הטלפון

כדי להתקין את האפליקציה על מסך הבית צריך שהיא תוגש דרך **HTTPS**
(או `localhost` לבדיקה). ניתן להעלות את תיקיית `meal-planner` לכל שירות
אחסון סטטי בחינם, למשל [GitHub Pages](https://pages.github.com/),
[Netlify](https://www.netlify.com/) או [Vercel](https://vercel.com/) -
פשוט העלו את תוכן התיקייה כפי שהיא (Static Site).

### אנדרואיד (Chrome)
1. פתחו את הכתובת של האפליקציה בכרום.
2. יופיע כפתור "⬇️ התקן אפליקציה" בראש המסך - לחצו עליו ואשרו.
3. אם לא הופיע: תפריט שלוש הנקודות ⋮ ⟵ "התקן אפליקציה" / "הוסף למסך הבית".

### iPhone (Safari)
Safari לא תומך בהתקנה אוטומטית, אז ההתקנה ידנית:
1. פתחו את כתובת האפליקציה ב-Safari (חובה Safari, לא כרום).
2. לחצו על כפתור השיתוף ⎋ בתחתית המסך.
3. גללו ובחרו "הוסף למסך הבית" (Add to Home Screen).
4. אשרו - האייקון יופיע במסך הבית ויפתח במסך מלא כמו אפליקציה רגילה.

לאחר ההתקנה הראשונה האפליקציה תעבוד גם ללא אינטרנט, כולל 20 המתכונים
המובנים, כי כל הקבצים נשמרים במטמון של ה-Service Worker.

## 🎨 יצירת האייקונים מחדש

האייקונים (`icons/*.png`) נוצרים באופן פרוצדורלי, בלי ספריות חיצוניות,
ע"י `scripts/generate-icons.mjs` (משתמש רק ב-`zlib` המובנה של Node
לקידוד PNG). כדי ליצור אותם מחדש (למשל אחרי שינוי צבעים):

```bash
node scripts/generate-icons.mjs
```

## 🎨 בנייה מחדש של קובץ ה-CSS (Tailwind)

עיצוב האפליקציה מבוסס על Tailwind CSS, אך **בניגוד לפתרונות נפוצים
האפליקציה לא טוענת את Tailwind מ-CDN בזמן ריצה** - הקובץ `css/tailwind.css`
הוא קובץ סטטי שכבר קומפל מראש, כדי שהעיצוב יטען באופן מיידי ואמין גם
בלי תלות ברשת חיצונית וגם באופליין מהרגע הראשון. אם משנים classes
ב-`index.html` או ב-`js/app.js` וצריך לרענן את קובץ ה-CSS:

```bash
cd meal-planner/scripts
npm install --no-save tailwindcss@latest @tailwindcss/cli@latest
npx @tailwindcss/cli -i ./tailwind-input.css -o ../css/tailwind.css --minify
```

(זהו שלב build חד-פעמי בזמן פיתוח בלבד - האפליקציה עצמה, לאחר יצירת
הקובץ, נשארת אפליקציה סטטית לגמרי ללא build step בזמן ריצה.)

## 🧱 טכנולוגיה

- HTML + Vanilla JavaScript (ES Modules), ללא framework וללא build step בזמן ריצה.
- Tailwind CSS, מקומפל מראש לקובץ סטטי (ולא נטען מ-CDN) לעיצוב מודרני, רספונסיבי ותומך RTL שעובד גם אופליין.
- גופן Heebo מ-Google Fonts לתמיכה נוחה בעברית.
- `localStorage` לשמירת נתונים.
- Web App Manifest + Service Worker להתקנה ותמיכה באופליין (PWA מלא).
- Web Share API / קישור `wa.me` לשיתוף רשימת הקניות בוואטסאפ.
